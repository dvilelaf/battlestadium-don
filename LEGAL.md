## What this repository does not contain

No disc image, no executable, no data file, no video or sound from the game, no translation of the game's code (the
C++ the recompiler produces), no memory dump. The repository holds tools, patches, original code and documentation.
There is no ready-to-play download, and none will be offered.

## What the player does

The player makes a disc image from **a copy of the game they own**, and their own PC generates and compiles the
program from it. The result stays on their machine, is for their personal use, and must not be shared. Do not
upload, share or ask for disc images, generated code or built game programs in this project's issues or
discussions.

The English fan translation by Lord Izen is a separate work by its author; it is not distributed here.

## Online play

Netplay exchanges only controller inputs and match state between players' own copies. Nothing of the game is sent.

## Contact and takedown

If you are a rights holder and think something in this repository should not be here, open an issue or contact the
maintainer and it will be reviewed promptly.
