# Multiplayer with two pads: the entry screen, a four-fighter match to the timer, its result, and back to the entry screen.
#
# Variant: the English one (en_patch/jpvoice/disc/SLPS_256.75). Player 1 and player 2 are pads (P2: lines); players 3 and 4 stay COM. Both press a fixed loop of walk/Square/Cross/Triangle every 300 blanks. The match ends on its timer at about blank 16500 (K.O., WINNER, a victory pose), then the entry editing screen comes back (journal 026); with --sound off the match ends about 600 blanks later than with sound, so the route stops at the WINNER screen.
# Landmarks (named shots; blank = vertical blank): logo_after_circle 3400, logo_greyed 3800, stage 4400, gaara_card 5000, timer_end 15900, countdown_3 16020, timer_003 16140, winner_screen 16560; it quits at 16700.
#
# Run it from the repository root (local.env loaded), with a folder for the shots:
#   DON_PLAY_MOVIES=1 DON_TRACE_FRAMES=1 build/linux-dev/don --headless --renderer software --sound off \
#       --shots work/shots/multiplayer_match --input-script tools/run/scripts/multiplayer_match.txt en_patch/jpvoice/disc/SLPS_256.75
# It belongs to the regression suite (tests/regression/): the md5 of every landmark is in
# tests/regression/routes.json. The timing holds with --sound off only (sound moves the blanks).
