# direct C++ call between recompiled functions must never be emitted to one of these addresses: the call has to keep
# going through the dispatcher or the replacement would be bypassed. The game checks at startup that every
# replaceFunction target is listed (a dev build exits with code 2 if one is missing; src/game/don_overrides.cpp).
#
